Credits

Visualizations: NASA Earth Information Center. A NASA Space Apps Challenge 2026 project.

Angular Lovers
We are Angular Lovers, a team of four: Emanuel Vinicius Sacoman, Guilherme de Souza Mota, Luiz Otavio dos Santos Morais and Yanna Himawari Ondani Tanigawa. For the NASA Space Apps Challenge 2026, we built Earth Jukebox, an interface that turns NASA Earth Information Center visualizations into sound, so that Earth science can be heard as well as seen.
Built with: Angular and TypeScript for the application; HTML (HyperText Markup Language) and CSS (Cascading Style Sheets) for structure and design; SVG for the icons; ARIA attributes for screen reader support; Node.js, npm (Node Package Manager) and nvm (Node Version Manager) for the development environment; and the Plus Jakarta Sans, Space Grotesk and JetBrains Mono typefaces.
