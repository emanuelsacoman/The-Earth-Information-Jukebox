## Como registrar

Criar `NNNN-short-name.md` com número sequencial, data, estado (`PROPOSTA`, `ACEITA`, `SUBSTITUÍDA` ou `REJEITADA`), contexto, decisão, alternativas, consequências, evidências, tarefas e decisões pendentes. Separar preferência da equipe de requisito externo verificado.

Escolhas com impacto em fonte/calibração, contrato, arquitetura, dependência, SSR/publicação ou escopo devem ter justificativa antes de mudanças amplas. Registrar recomendação e impactos quando uma decisão parecer inadequada; revisão humana define aceite. Não apagar histórico: uma nova ADR referencia e substitui a anterior.

Pequenos ajustes dentro de uma decisão existente podem ficar na tarefa. Atualizar este índice, [roadmap](../roadmap.md), [riscos](../risks.md) e [handoff](../handoff.md) quando a decisão alterar a sequência de trabalho.
