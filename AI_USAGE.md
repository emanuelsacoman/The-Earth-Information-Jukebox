# AI assistance disclosure

AI coding assistants, including OpenAI Codex, assisted with design exploration, implementation, debugging, test development, code review and documentation. The user selected the free-exploration direction and amber/graphite visual style from discussed alternatives. The team must review this account and the origin of its challenge solution idea against the official submission guide; this document does not assert that all ideation was exclusively human.

The shipped NASA imagery originates from NASA SVS, as recorded in `public/data/night-lights/manifest.json`. The workflow used conventional image resizing and format conversion under AI-assisted development; it does not invent satellite observations. Natural Earth provides the globe's base geography, with credits next to the renderer. No AI-generated illustration is included in the running application.

Audio is generated at runtime by a deterministic, AI-assisted sonification implementation using the Web Audio API. Brightness statistics select musical notes and gain; horizontal position sets stereo panorama; there is no generative audio model or prerecorded AI soundtrack. This is an artistic mapping of image pixels, not a calibrated physical measurement or an acoustic recording of Earth.

Project and source-code assistance is declared here and in `public/project-metadata.json`; the application links that metadata from Method, credits and limitations. AI also assisted with the English submission draft and demo script. Team names, member identities, final links, actual human listening and screen-reader validation remain subject to human confirmation. No NASA endorsement or final submission is claimed.
